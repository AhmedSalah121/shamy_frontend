# Shamy

A usable website for coordinating office breakfast orders with automated **Pickup Hero** draws, upfront multi-payer tracking, and precision bill tracking.

Built with **Next.js (App Router)** and **TypeScript**, following **Clean Architecture**, **SOLID principles**.

---

## ⚡ Key Features

1. **Strict Pickup Hero Rule (Section 7.1)**:
   The wheel randomly selects from joined colleagues.
2. **Order Arrived Live Broadcast (Section 7.2)**:
   Hero or Creator can broadcast arrival, which triggers an in-app notification, and toast alert.
3. **Multi-Payer Upfront Settlement (Section 8)**:
   Allows multiple colleagues to front cash at the door.
